Extensiones y Ruby API

SketchUp es potente por defecto, pero sus extensiones lo convierten en una herramienta casi ilimitada. Aprende a encontrar, instalar y crear extensiones con la Ruby API.

Extension Warehouse

Extension Warehouse es la tienda oficial de extensiones para SketchUp. Accede desde Window → Extension Warehouse dentro de SketchUp, o desde el navegador en extensions.sketchup.com.

Extensiones gratuitas

Herramientas útiles sin costo: Joint Push Pull, FredoScale, Curviloft, Soap Skin & Bubble.

Extensiones de pago

Soluciones profesionales: Profile Builder, SketchUV, Renderer Pro, PlusSpec.

Verificación

Extensiones verificadas por Trimble. Busca el sello de "Verified" para mayor seguridad.

Actualizaciones

Las extensiones se actualizan desde Window → Extension Manager → Updates.

Tip: antes de instalar una extensión, verifica que sea compatible con tu versión de SketchUp. Lee reseñas y revisa la fecha de la última actualización.

Cómo instalar extensiones

MétodoPasos
Desde Extension Warehouse Busca la extensión → clic "Install" → acepta los permisos → reinicia SketchUp.
Desde un archivo .rbz Window → Extension Manager → Install Extension → selecciona el archivo .rbz → reinicia.
Manual (desarrolladores) Copia la carpeta de la extensión a la carpeta Plugins de SketchUp.

Precaución: solo instala extensiones de fuentes confiables. Una extensión mal programada puede corromper tu archivo o causar errores inesperados. Haz copias de seguridad antes de trabajar con extensiones nuevas.

Ruby API: automatiza SketchUp

SketchUp incluye un intérprete de Ruby que permite programar extensiones y scripts personalizados. No necesitas ser programador para empezar:许多 extensiones populares empezaron como scripts simples de 10 líneas.

Abrir la consola de Ruby

Versión de SketchUpCómo abrir la consola
SketchUp Pro (Windows/Mac)Window → Ruby Console
SketchUp for WebNo disponible (solo versión Pro)

Ejemplos básicos

Prueba estos comandos en la consola de Ruby:

Crear un rectángulo:

model = Sketchup.active_model
entities = model.active_entities
pts = [Geom::Point3d.new(0,0,0), Geom::Point3d.new(100,0,0),
      Geom::Point3d.new(100,100,0), Geom::Point3d.new(0,100,0)]
face = entities.add_face(pts)

Extruir una cara (Push/Pull):

face = model.active_entities.grep(Sketchup::Face).last
face.pushpull(50)

Contar entidades del modelo:

model.active_entities.length

Estructura de una extensión

Una extensión de SketchUp es un archivo .rb (o carpeta con varios .rb) que se carga automáticamente al iniciar SketchUp. La estructura mínima es:

# mi_extension.rb
module MiExtension
  def self.init
    # Código de inicialización
  end
end

if not file_loaded?("mi_extension.rb")
  MiExtension.init
  file_loaded("mi_extension.rb")
end

Tip: si quieres aprender Ruby API, estudia el código de extensiones gratuitas en GitHub. La mayoría son código abierto y puedes ver exactamente cómo están hechas.

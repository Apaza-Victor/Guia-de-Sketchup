Capas y etiquetas (Tags)

Las etiquetas no organizan geometría — organizan visibilidad. Entender esa diferencia evita el 90% de los modelos desordenados.

Qué son (y qué no son) las etiquetas

Desde SketchUp 2020, lo que antes se llamaba "Capas" (Layers) se renombró a Tags (etiquetas) — un cambio de nombre deliberado, porque en SketchUp una etiqueta no contiene geometría como en AutoCAD; solo controla si un grupo o componente es visible o no.

Regla de oro: nunca dibujes geometría "suelta" (líneas, caras) directamente sobre una etiqueta distinta de Sin etiquetar. Dibuja siempre en Sin etiquetar, agrupa esa geometría, y aplica la etiqueta al grupo completo. Romper esta regla es la causa número uno de "geometría fantasma" que reaparece al reactivar una etiqueta.

Organización típica por disciplina

En un proyecto de arquitectura, una estructura de etiquetas común se ve así:

  • Estructura
  • Mobiliario
  • Acabados
  • Vegetación
  • Cotas y anotaciones

Con esta estructura, puedes ocultar "Vegetación" y "Cotas" para revisar la estructura pura, o mostrar solo "Mobiliario" y "Acabados" para una vista de presentación — sin borrar nada.

Escenas: fotografías del estado del modelo

Una escena (pestaña en la parte superior del viewport) guarda una combinación de: posición de cámara, qué etiquetas están visibles, el estilo activo y la ubicación de la sección. Son la base para:

Presentaciones

Alterna entre vistas guardadas para explicar un proyecto paso a paso.

Exportación a LayOut

Cada viewport de LayOut referencia una escena específica de SketchUp.

Animaciones

SketchUp interpola entre escenas consecutivas para crear recorridos.

Tip: al crear una escena, desmarca "Propiedades de estilo" si solo quieres que guarde cámara y visibilidad de etiquetas — así puedes cambiar el estilo global del proyecto sin que cada escena antigua lo sobreescriba.

Mini-ejercicio

Practica ahora: crea 3 etiquetas (Estructura, Mobiliario, Acabados), asigna cada grupo de tu modelo a la etiqueta correspondiente, y guarda dos escenas: una con todo visible y otra mostrando solo "Estructura".

Grupos y componentes

Sin organización, un modelo de SketchUp se vuelve inmanejable rápidamente. Grupos y componentes son las herramientas clave para mantener tu geometría separada, editable y escalable.

¿Por qué necesitas agrupar geometría?

En SketchUp, toda geometría suelta se "pega" entre sí automáticamente. Si dibujas una pared y luego una ventana sobre ella, al mover la ventana moverás parte de la pared. Los grupos y componentes crean contenedores que aíslan la geometría, evitando este comportamiento.

Problema común: si intentas mover un objeto y se deforma o arrastra caras vecinas, es porque la geometría no está agrupada. Primero agrupa, luego mueve.

Grupos: contenedores básicos

Un grupo es un contenedor simple que aísla geometría. Lo creas seleccionando toda la geometía y presionando Ctrl+G. Para editarlo, haz doble clic sobre él.

Crear grupo

Selecciona geometría → clic derecho → "Make Group" o Ctrl+G.

Editar grupo

Doble clic para entrar. El resto del modelo se atenúa. Esc o clic fuera para salir.

Explorar grupo

Clic derecho → "Explode" para volver a convertirlo en geometría suelta.

Tip: siempre agrupa tu geometría antes de combinarla con otra cosa. Un buen hábito es seleccionar todo (Ctrl+A) y agrupar después de terminar cada pieza.

Componentes: grupos con inteligencia

Un componente es como un grupo, pero con una ventaja clave: todas sus copias (instancias) están vinculadas. Si editas un componente, todas las instancias se actualizan al instante. Ideal para objetos repetidos como sillas, ventanas o columnas.

Rendimiento (modelos grandes)MenorMayor (una definición, muchas copias)

Regla práctica: usa grupos para geometría única (paredes, suelos) y componentes para objetos que se repiten (muebles, ventanas, accesorios).

Componentes dinámicos (vista previa)

SketchUp Pro incluye componentes dinámicos: componentes con comportamientos paramétricos (por ejemplo, una puerta que cambia de tamaño al arrastrar). Se configuran con el editor de componentes dinámicos y no requieren programación.

Aviso: los componentes dinámicos son una función de SketchUp Pro. Si usas la versión gratuita (SketchUp for Web), esta característica no estará disponible.

Mini-ejercicio

Practica ahora: crea una mesa simple (4 patas + tablero) y conviértela en un componente. Luego duplica la mesa 3 veces. Edita el componente original para cambiar el grosor del tablero y observa cómo todas las copias se actualizan.
